# CSV成绩导入示例

仅支持UTF-8 CSV，不需要Excel或Python运行环境。新格式：学号、姓名、科目、成绩；原三列格式及英文表头继续兼容。

初始化样本后，用 **T0004 / Teacher123** 登录，选择CSV批量导入→24级软件1班：

- `成功_软件1班_C语言.csv`：为何雨（240101010）补录88分。预览后确认才写入；再次导入因已有成绩而拒绝。
- `失败_姓名与分数.csv`：分别演示姓名不匹配和120分越界，错误逐行列出，整批不导入。
- `成绩导入模板.csv`：空白表头，按真实档案填写；学号保留前导零。

教师只能导入所选班级中有授课权限学生的任教科目。路径不加外层引号，输入 `:q` 取消。
