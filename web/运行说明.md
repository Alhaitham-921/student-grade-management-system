# 网页端运行说明

在项目根目录执行 `./启动网页端.ps1`，随后打开 http://localhost:3000 。需要 VS2022 C++ 桌面工具、Node.js 22.12+，首次启动下载 npm 依赖；Python 仅用于验证脚本。

- 本机：`./启动网页端.ps1`
- 局域网：`./启动网页端.ps1 -Lan`，其他设备访问服务器电脑的局域网 IPv4 地址和3000端口；按本机防火墙策略允许该端口。
- 独立演示：`./启动网页端.ps1 -Demo`；每次创建新的演示数据目录，登录管理员后在系统管理中补充示例数据。
- 自定义：`./启动网页端.ps1 -DataDir 'F:\专用数据目录' -Port 3100`
- 只构建：`./启动网页端.ps1 -BuildOnly`

默认工作目录为当前维护源码目录，使用原有账号及 `.sgms` 数据。空目录初始管理员 admin/admin，登录后必须改密。新密码6–19 UTF-8字节。已有数据不会自动补样本或重置密码。示例教师工号以系统管理账号列表为准，密码 Teacher123；学生账号与初始密码均为完整学号。

网页端与控制台共用同一数据格式和目录锁，须关闭其中一个后再启动另一个；网页内允许多人登录。退出网页服务用 Ctrl+C。服务重启后会话失效。业务保存仍由 C 核心原子提交，Node 不直接写入 DAT。备份需关闭服务，完整复制 `.sgms` 到新位置。

前端位于 web，C协议入口位于 native-web，维护源码和原控制台入口保留。C JSON解析使用cJSON 1.7.19，其许可证随源码保存。构建使用独立时间目录，Vite不自动清空输出；不自动清理数据、构建结果或测试现场。

开发：先启动服务，再在web目录执行 `npm run dev`，开发服务器代理 /api 到3000端口。正式构建 `npm run build`，页面和API由同一Node服务提供。

验证：在全新独立演示服务启动后执行 `python -X utf8 web/verify_web.py`。此脚本会初始化该演示管理员、补充样本并新增测试学生，不可针对现有业务目录执行；不执行删除或清空。删除和清空需另外明确授权后测试。错误预览或并发修改会拒绝提交；提交超时或进程异常时先刷新核对，不自动重试写入。

当前限本机及可信局域网，默认HTTP。保留100用户、100学生、50班级、每生10科及10教师限制。管理员仅查询和导出成绩；学生仅查看本人；教师写权限由C进程重新验证。无学期、考试批次或公网部署。
